わたしの3Dキャラクター Webアプリ（試作版）

使い方:
1. このZIPを展開します。
2. index.html と6個の .glb ファイルを同じフォルダに置いたままにします。
3. Webページとして公開すると動作します（例: GitHub Pages）。
   index.html をPCのファイルから直接開くと、ブラウザの制限でGLBが読み込めない場合があります。
4. iPhoneでは、公開したページをSafariで開き「共有」→「ホーム画面に追加」でアプリ風に起動できます。

注意:
- Three.jsをCDNから読み込むため、初回読み込みにはインターネット接続が必要です。
- 各ボタンはそれぞれのGLBを読み込み直します。
- これは6つのGLBを使った初期試作です。顔の表情や口パク機能はまだ含みません。
